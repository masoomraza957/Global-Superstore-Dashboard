# 📊 Global Superstore Sales Dashboard
![Global Superstore Dashboard](https://raw.githubusercontent.com/masoomraza957/Global-Superstore-Dashboard/main/Global%20Superstore%20Dashboard.png)

## 📌 Project Overview

This project is an interactive Sales Dashboard built in Microsoft Excel using the Global Superstore dataset. The dashboard provides insights into sales, profit, orders, customer segments, product categories, markets, and regions through interactive visualizations.

## 🚀 Features

- Interactive Dashboard
- KPI Cards
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline Filter
- Business Insights

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Data Cleaning
- Dashboard Design

## 📈 Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Discount
